Wakeful

A tray app for KDE Plasma 6 that keeps the computer awake for a set time — sleep only, or with the screen on too — then releases the block by itself, and leaves nothing behind if it crashes.

Plasma's own "Manually block sleep and screen locking" switch has no time limit and always keeps the screen on too. Wakeful blocks sleep for 30 minutes, a few hours, or until you turn it off, and by default lets the screen dim, turn off and lock as usual.

Not yet released. No release has been published yet, so the APT and DNF repositories below do not exist yet; the Nix flake works now. Follow the repository for the first release.

Debian/Ubuntu (APT)

Debian 13, Ubuntu 25.04 and later (Plasma 6).

# Add the GPG key
curl -fsSL https://stuckj.github.io/wakeful/gpg-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/wakeful.gpg

# Add the repository
echo "deb [signed-by=/usr/share/keyrings/wakeful.gpg] https://stuckj.github.io/wakeful/apt stable main" | sudo tee /etc/apt/sources.list.d/wakeful.list

# Install
sudo apt update
sudo apt install wakeful

This repository carries the current release only. To install or pin an older version, add the archive repository below, which indexes every version published. Enabling both is safe: they are two sources for the same package.

Debian/Ubuntu (APT) — full version history

echo "deb [signed-by=/usr/share/keyrings/wakeful.gpg] https://github.com/stuckj/wakeful/releases/download/apt-history/ ./" | sudo tee /etc/apt/sources.list.d/wakeful-history.list

sudo apt update
apt list -a wakeful

Fedora (DNF)

Fedora 40 and later. Indexes every version published.

sudo tee /etc/yum.repos.d/wakeful.repo << 'REPO'
[wakeful]
name=wakeful
baseurl=https://stuckj.github.io/wakeful/yum
enabled=1
gpgcheck=1
gpgkey=https://stuckj.github.io/wakeful/yum/gpg-key.asc
REPO

sudo dnf install wakeful

Nix

# Home Manager: install it and start it with the Plasma session
inputs.wakeful.url = "github:stuckj/wakeful";
imports = [ inputs.wakeful.homeManagerModules.default ];
services.wakeful.enable = true;

# NixOS without Home Manager
imports = [ inputs.wakeful.nixosModules.default ];
programs.wakeful.enable = true;

# Or just the package
nix profile install github:stuckj/wakeful

Where the packages live

Package files are served from the per-version GitHub releases; these repositories carry only the indexes.
